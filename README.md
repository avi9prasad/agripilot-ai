# AgriPilotAI

An AI farm advisor: log soil, weather, and nutrient readings per field zone and get
concrete irrigation, fertilizer, and pest-risk recommendations — generated by Claude,
inspired by the precision-agriculture patterns in freeCodeCamp's
["AI in Agriculture" book](https://www.freecodecamp.org/news/ai-in-agriculture-book/).

Built for the **WeMakeDevs × Zerops Challenge** (Aug 8–9, 2026).

## Stack

- **Client**: React 18 + Vite
- **Server**: Express (single Node process serves the API and the built client — one container)
- **AI**: Anthropic Claude via `@anthropic-ai/sdk`, with a deterministic rule-based
  fallback if no API key is set (so the app still demos without exposing a key to judges)

## Run locally

```bash
npm run install:all

# terminal 1
npm run dev:server

# terminal 2
npm run dev:client
```

Visit `http://localhost:5173`. Copy `server/.env.example` to `server/.env` and add
`ANTHROPIC_API_KEY` for real AI-generated recommendations (otherwise the heuristic
fallback kicks in).

## Production build (what Zerops runs)

```bash
npm run build   # installs deps + builds the client into client/dist
npm start        # single Express process serves API + static client on $PORT
```

## Deploy on Zerops

1. Push this repo to GitHub.
2. Create a Zerops project, import from GitHub, and let it pick up `zerops.yml`
   (Node.js 20 service, `npm run build` → `npm start`, port 3000).
3. Add the `ANTHROPIC_API_KEY` environment variable in the Zerops service's env vars
   (and optionally `ANTHROPIC_MODEL` to override the default `claude-sonnet-4-5`).
4. Deploy. The service serves both the API (`/api/advisor/recommend`) and the
   built React app from the same URL.

## API

`POST /api/advisor/recommend`

```json
{
  "context": { "cropType": "wheat", "growthStage": "flowering", "region": "Punjab, India" },
  "zones": [
    { "name": "Zone A", "soilMoisture": 35, "temperature": 24, "humidity": 55, "nutrientLevel": "low" }
  ]
}
```

Returns a summary, per-zone irrigation/fertilizer/pest guidance with a priority and
risk level, and one sustainability tip.
